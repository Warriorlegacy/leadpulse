# LeadPulse — Competitor Analysis

Status: qualitative context only. **No verified competitor data was obtained.** No paid market data, no pricing verification, no feature audit, and no primary buyer interviews. Every statement about a named product below is labelled `unverified` and is perception-level, not a factual comparison. No market share, pricing, funding, or customer counts are asserted.

## 1. How to read this file

- Products are listed as **contextual references** for the CRM / lead-management category, not as a researched competitive set.
- The "Qualitative note" column is a hypothesis about category positioning. It is `unverified` and may be wrong.
- If a competitor fact cannot be verified, it is marked `unverified` — no inference is filled in.

## 2. Narrow differentiation hypothesis (unvalidated)

- [PRD.md](PRD.md) positions LeadPulse on **response-time discipline + source attribution for small teams**: every lead has an owner, a next action, and a measurable response time.
- It is `unverified` whether the products above already do this well, and `unverified` whether buyers regard it as a reason to switch or pay.
- The differentiation is deliberately narrow. Breadth (outbound automation, AI, billing) is an explicit MVP non-goal ([PRD.md](PRD.md)), partly because no providers are configured ([ASSUMPTIONS.md](ASSUMPTIONS.md)).

## Category framing

The six names were chosen as widely recognised anchors for "tools a small team might already use for leads". They are not a ranked shortlist, not a market-share sample, and not the result of a sourcing exercise. Inclusion implies no endorsement and no verified comparison. Other products could serve the same framing role.
